# Legal / ethics memo — public-data documentation only

**Product:** Abu Hureirah Situation Room · Sudan Wing  
**Audience:** journalists, academics, human-rights archivists, nonprofit researchers

## Purpose

Document military, security, logistics, and civilian activity in Sudan and adjacent border areas using **only publicly available** satellite, flight, AIS, and open reporting. Outputs support journalism, archival, early warning context, and accountability records.

## Prohibited uses

Targeting, fire control, strike planning, real-time tactical advice to armed actors, kill-chain or aim-point language, ranking “best targets,” or recommending attacks or interdiction. If asked, the product stays in documentation mode and refuses.

## Data policy

- Optical / thermal / ADS-B / AIS from public APIs and catalogs only.
- No scraping of paywalled commercial imagery.
- FIRMS is a thermal anomaly feed, not a strike feed.
- ADS-B silence is not absence of a flight; cargo is never inferred from airframe type alone.
- Party labels are assessments with written reasons and an audit trail.

## Evidentiary standard

Observation ≠ identification ≠ assessment ≠ judgment. Confidence uses the 1–5 rubric. Multi-party symmetry (SAF, RSF, other armed, civilian, unknown). Negative evidence is recorded. Nothing is “confirmed” without a human review click.

## Export

Every GeoJSON, CSV, and briefing carries the limitations caveat and a methods appendix. UI badge: **DOCS ONLY**.
